# Маппинг полей: Рабочая карта обследования EXPERTUS

Единый источник истины для соответствия «поле в форме / в документе» ↔ ключ в API и плейсхолдер в шаблоне.

**Формат даты в документе:** ДД.ММ.ГГГГ (например 05.02.2026).

**Пустые значения:** для необязательных текстовых полей при отсутствии данных подставляется прочерк «—».

---

| Поле в форме / документе           | Ключ API / плейсхолдер в шаблоне | Тип      | Обязательное | Значение по умолчанию |
|------------------------------------|----------------------------------|----------|--------------|------------------------|
| Заказчик (Договор/проект)          | `customer` / `{{customer}}`      | string   | Нет          | —                      |
| Наименование объекта обследования | `object_name` / `{{object_name}}`| string   | Нет          | —                      |
| Место нахождения                  | `location` / `{{location}}`      | string   | Нет          | —                      |
| Инв.№                             | `inventory_number` / `{{inventory_number}}` | string | Нет | —        |
| Зав. №                             | `factory_number` / `{{factory_number}}`    | string | Нет | —        |
| Ф.И.О. исполнителя                | `inspector_name` / `{{inspector_name}}`    | string | Нет* | Исполнитель (или из аккаунта) |
| Дата обследования                  | `inspection_date` / `{{inspection_date}}` | date  | **Да** | — (формат ДД.ММ.ГГГГ) |
| Температура воздуха, °C           | `temperature_c` / `{{temperature_c}}`     | float | Нет | —        |
| Влажность воздуха, %              | `humidity_percent` / `{{humidity_percent}}`| float | Нет | —        |
| Уровень освещенности, лк          | `illumination_lux` / `{{illumination_lux}}`| float | Нет | —       |
| Комплект ВИК                       | `equipment_vik` / `{{equipment_vik}}`      | string | Нет | —        |
| Комплект пенетрантов ПВК          | `equipment_penetrant` / `{{equipment_penetrant}}` | string | Нет | — |
| Ультразвуковой дефектоскоп        | `equipment_defectoscope` / `{{equipment_defectoscope}}` | string | Нет | — |
| Ультразвуковой толщиномер         | `equipment_thickness_gauge` / `{{equipment_thickness_gauge}}` | string | Нет | — |
| Твердомер                         | `equipment_hardness` / `{{equipment_hardness}}` | string | Нет | — |
| Состояние рабочей документации    | `documentation_state` → `documentation_line` | string | Нет | строка с вариантами и отметкой [x] |

\* Ф.И.О. исполнителя: если не передано в запросе, бэкенд подставляет из текущего пользователя (аккаунт) или «Исполнитель».

---

## Специальные поля

- **documentation_line** — в шаблон подставляется не сырое значение, а строка с одним отмеченным вариантом: «удовлетворительно [x]», «неудовлетворительно [x]» или «отсутствует/ не предоставлена [x]». Ключ в API: `documentation_state` (значения: удовлетворительно / неудовлетворительно / отсутствует и т.п.).

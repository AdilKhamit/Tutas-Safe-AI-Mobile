# Шаблоны документов

## Рабочая карта обследования EXPERTUS

Форма Ф-EXP-ДП-ИЛ-7.8-03. Генерация документа по шаблону с подстановкой данных из API.

### Поддерживаемые форматы (приоритет)

1. **inspection_card_template.dotx** — **основной шаблон**: при наличии этого файла он используется строго. Редактируйте .dotx в Word — все сгенерированные карты будут по нему.
2. **inspection_card_template.docx** — используется, если .dotx отсутствует
3. **inspection_card_template.doc** — старый формат; при наличии LibreOffice конвертируется в .docx при первом запросе

### Плейсхолдеры в шаблоне

В шаблоне используются плейсхолдеры `{{key}}`. Пустые необязательные поля подставляются как «—». Формат даты: **ДД.ММ.ГГГГ**.

| Плейсхолдер | Описание |
|-------------|----------|
| `{{inspector_name}}` | Ф.И.О. исполнителя |
| `{{inspection_date}}` | Дата обследования (ДД.ММ.ГГГГ) |
| `{{customer}}` | Заказчик (Договор/проект) |
| `{{object_name}}` | Наименование объекта обследования |
| `{{location}}` | Место нахождения |
| `{{inventory_number}}` | Инв.№ |
| `{{factory_number}}` | Зав. № |
| `{{temperature_c}}` | Температура воздуха, °C |
| `{{humidity_percent}}` | Влажность воздуха, % |
| `{{illumination_lux}}` | Уровень освещенности, лк |
| `{{equipment_vik}}` | Комплект ВИК |
| `{{equipment_penetrant}}` | Комплект пенетрантов ПВК |
| `{{equipment_defectoscope}}` | Ультразвуковой дефектоскоп |
| `{{equipment_thickness_gauge}}` | Ультразвуковой толщиномер |
| `{{equipment_hardness}}` | Твердомер |
| `{{documentation_line}}` | Строка состояния документации (удовлетворительно [x] / неудовлетворительно [x] / отсутствует [x]) |
| `{{defects_notes}}` | Дефектная ведомость / примечания |
| `{{sketch_note}}` | Эскиз, схема объекта |

**Полная таблица полей (поле формы ↔ ключ API, тип, умолчания):** см. [FIELD_MAPPING.md](FIELD_MAPPING.md).

### Как править шаблон (строго по вашему .dotx)

**Рекомендуемый способ:** править **inspection_card_template.dotx** в Word.

1. Откройте **inspection_card_template.dotx** в Word (или LibreOffice).
2. Меняйте оформление, подписи, порядок блоков как нужно — это и будет использоваться при генерации.
3. В местах, куда подставляются данные, должны стоять плейсхолдеры по [FIELD_MAPPING.md](FIELD_MAPPING.md): `{{customer}}`, `{{inspection_date}}`, `{{object_name}}` и т.д.
4. Сохраните **inspection_card_template.dotx** в эту папку (`backend/app/templates/`).  
   При наличии .dotx бэкенд использует **только его**; файл .docx при этом не используется.

### Если у вас только файл «Рабочая карта обследования EXPERTUS.doc»

1. Откройте его в Word, сохраните как **Шаблон Word (.dotx)** в эту папку как **inspection_card_template.dotx** (или сначала .docx, затем переименуйте в .dotx / сохраните как .dotx).
2. В открытом шаблоне замените поля для ввода на плейсхолдеры по таблице выше.
3. При добавлении новых полей обновите схему `InspectionCardGenerate`, сервис `inspection_card_service.py` и [FIELD_MAPPING.md](FIELD_MAPPING.md).

### Автоматическая генерация эталонного шаблона (только плейсхолдеры)

Из корня backend можно сгенерировать .docx с уже вставленными плейсхолдерами:

```bash
cd backend && python scripts/generate_inspection_template.py
```

Скрипт создаёт/перезаписывает `app/templates/inspection_card_template.docx` с разметкой по плейсхолдерам. При необходимости отредактируйте оформление в Word.

### Нормативы

Форма ориентирована на стандарты неразрушающего контроля и обследований; при необходимости сверяйте с ГОСТ 31937, ГОСТ Р ИСО 17637, ГОСТ Р 3.102-2024 (ЕСТД, с 01.01.2026).

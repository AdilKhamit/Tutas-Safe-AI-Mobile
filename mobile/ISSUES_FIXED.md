## ⚠️ Проблемы, требующие внимания

### 1. Файл .env
**Проблема:** Файл `.env` отсутствует или заблокирован для редактирования.

**Решение:** Создайте файл `.env` в корне папки `mobile/` со следующим содержимым:
```env
# API Configuration
API_BASE_URL=http://192.168.8.108:8000
API_VERSION=v1
API_KEY=dev-api-key-12345

# Environment
ENVIRONMENT=development
DEBUG=true
LOG_LEVEL=INFO

# Timeouts
CONNECT_TIMEOUT=10
RECEIVE_TIMEOUT=30

# AI Engine Configuration
AI_ENGINE_URL=http://localhost:8001
AI_ENGINE_PORT=8001

# Sync Configuration
SYNC_BATCH_SIZE=100
SYNC_RETRY_ATTEMPTS=3
SYNC_RETRY_DELAY_SECONDS=5

# MinIO Configuration
MINIO_ENDPOINT=localhost:9000
MINIO_USE_SSL=false
MINIO_BUCKET_PHOTOS=tutas-photos
MINIO_BUCKET_REPORTS=tutas-reports

# Domain Configuration
DOMAIN=localhost
BACKEND_PORT=8000
```

**Важно:** Убедитесь, что файл `.env` добавлен в `pubspec.yaml` в секцию `assets`:
```yaml
flutter:
  assets:
    - .env
```

### 2. Генерация кода
**Проблема:** Возможно, не сгенерированы файлы `.g.dart` для:
- `database.g.dart`
- `defect_dto.g.dart`
- `pipe_dto.g.dart`

**Решение:** Запустите генерацию кода:
```bash
cd mobile
flutter pub get
flutter pub run build_runner build --delete-conflicting-outputs
```

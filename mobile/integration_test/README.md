# Integration Tests

Интеграционные тесты для критичных пользовательских сценариев.

## Структура

```
integration_test/
├── app_test.dart                    # Базовый тест запуска приложения
├── navigation_flow_test.dart        # Тест навигации между экранами
├── auth_flow_test.dart              # Тест аутентификации (структура)
├── qr_scan_flow_test.dart           # Тест сканирования QR (структура)
├── offline_sync_flow_test.dart      # Тест офлайн синхронизации (структура)
└── helpers/
    └── integration_test_helpers.dart # Вспомогательные функции
```

## Запуск тестов

### Запуск всех integration тестов

```bash
flutter test integration_test/
```

### Запуск конкретного теста

```bash
flutter test integration_test/app_test.dart
```

### Запуск на устройстве/эмуляторе

```bash
flutter drive \
  --driver=test_driver/integration_test.dart \
  --target=integration_test/app_test.dart
```

## Критичные сценарии для тестирования

1. **Аутентификация**
   - Вход с email/password
   - Биометрическая аутентификация
   - Выход из системы

2. **Навигация**
   - Переключение между вкладками
   - Deep linking
   - Навигация назад

3. **QR сканирование**
   - Сканирование QR-кода
   - Просмотр деталей трубы
   - Создание дефекта

4. **Офлайн синхронизация**
   - Создание дефекта офлайн
   - Восстановление соединения
   - Автоматическая синхронизация

## Примечания

- Integration тесты требуют запущенного приложения
- Некоторые тесты могут требовать мокирования API
- Тесты должны быть независимыми и изолированными
- Текущие тесты содержат структуру для будущей реализации
- Для полной реализации требуется:
  - Настройка тестового окружения
  - Мокирование внешних зависимостей (камера, сеть)
  - Тестовые данные и учетные записи

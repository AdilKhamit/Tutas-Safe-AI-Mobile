# Установка на iPhone (физическое устройство)

Пошаговая настройка проекта на подключённом iPhone.

---

## 1. Режим разработчика на iPhone (обязательно)

На **iOS 16 и новее** для запуска приложений с Mac нужен режим разработчика.

### Как включить

1. Подключите iPhone к Mac кабелем.
2. На iPhone: **Настройки** → **Конфиденциальность и безопасность**.
3. Прокрутите вниз до раздела **Режим разработчика**.
4. Включите **Режим разработчика**.
5. Подтвердите перезагрузку устройства.
6. После перезагрузки подтвердите включение режима.

Если пункта «Режим разработчика» нет — проверьте, что iOS 16+ и что устройство хотя бы раз было подключено к Xcode/компьютеру для разработки.

---

## 2. Доверие компьютеру

1. Подключите iPhone по USB.
2. На iPhone при запросе «Доверять этому компьютеру?» нажмите **Доверять**.
3. При необходимости введите пароль/ Face ID.

---

## 3. Установка окружения на Mac

Убедитесь, что установлены:

- **Xcode** (из App Store) и командная строка:  
  `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`
- **Flutter**: [flutter.dev/docs/get-started/install/macos](https://docs.flutter.dev/get-started/install/macos)
- **CocoaPods**: `sudo gem install cocoapods`

---

## 4. Сборка и запуск на iPhone

### Вариант A: Скрипт (рекомендуется)

```bash
cd mobile
chmod +x install_ios.sh
./install_ios.sh
```

Скрипт проверит устройство, создаст `.env` при необходимости и установит приложение на iPhone.

### Вариант B: Вручную

```bash
cd mobile

# Зависимости Flutter
flutter pub get

# iOS-зависимости
cd ios && pod install && cd ..

# Проверить, что iPhone виден
flutter devices

# Запуск на подключённом iPhone (подставьте id из flutter devices при нескольких устройствах)
flutter run
# или явно: flutter run -d <device_id>
```

### Вариант C: Через Xcode

```bash
cd mobile
open ios/Runner.xcworkspace
```

В Xcode:

1. Выберите **Runner** → вкладка **Signing & Capabilities** → укажите свою **Team** (Apple ID).
2. В списке устройств выберите ваш iPhone.
3. Нажмите **Run** (▶️).

При первом запуске на iPhone: **Настройки** → **Основные** → **VPN и управление устройством** → выберите ваш профиль разработчика → **Доверять**.

---

## 5. Конфигурация (.env)

Если файла `mobile/.env` ещё нет:

```bash
cd mobile
cp .env.example .env
```

В `.env` укажите адрес бэкенда (для телефона — IP вашего Mac в локальной сети, не `localhost`):

```
API_BASE_URL=http://192.168.x.x:8000
API_KEY=dev-api-key-12345
```

## Частые проблемы

| Проблема | Решение |
|----------|--------|
| iPhone не в списке `flutter devices` | Включите режим разработчика, перезагрузите iPhone, переподключите кабель, нажмите «Доверять». |
| «Untrusted Developer» | Настройки → Основные → VPN и управление устройством → Доверять разработчику. |
| Ошибки подписи в Xcode | Выберите Team в Signing & Capabilities, проверьте Bundle ID. |
| «Could not find an option named release» | Используйте `flutter run` без `--release` или обновите Flutter. |

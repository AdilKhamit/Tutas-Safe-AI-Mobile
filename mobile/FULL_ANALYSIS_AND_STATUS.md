#### 6. ✅ Нет retry логики для сетевых запросов

**Решение:** Добавлен метод `_retryWithBackoff` с exponential backoff для всех API вызовов  
**Файлы:** `mobile/lib/data/api/api_client.dart`  
**📚 Лучшие практики из интернета:** [Retry в Go: От граблей к дзену отказоустойчивости](https://habr.com/ru/articles/903576), [Лучшие практики создания отказоустойчивых систем](https://habr.com/ru/articles/896638)
- ✅ Использован **exponential backoff** (1s → 2s → 4s → 8s) вместо фиксированной задержки
- ✅ Добавлен **jitter** (случайный разброс) для предотвращения "thundering herd" эффекта
- ✅ Ограничено количество попыток (максимум 3)
- ✅ Различаются типы ошибок: retry только временные (timeout, 5xx), не retry 4xx ошибки

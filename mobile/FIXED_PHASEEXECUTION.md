# ✅ Исправлена ошибка PhaseScriptExecution

## Проблема была найдена и исправлена!

**Реальная причина:** В файле `map_screen.dart` использовались несуществующие параметры для `TileLayer`:
- `tileFadeInStart` ❌
- `tileFadeInDuration` ❌  
- `errorTileCallback` ❌

Эти параметры не поддерживаются в версии `flutter_map 7.0.2`.

## ✅ Что было исправлено:

1. Удалены несуществующие параметры из `TileLayer`
2. Сборка теперь проходит успешно: `✓ Built build/ios/iphoneos/Runner.app`

## 📱 Установка на iPhone

Теперь можно установить приложение через Xcode:

### Шаг 1: Откройте проект
```bash
cd mobile
open ios/Runner.xcworkspace
```

### Шаг 2: В Xcode
1. Выберите устройство **iPhone (Әділет)** в верхней панели
2. Перейдите в **Signing & Capabilities**
3. Выберите вашу команду разработчика (Team)
4. Нажмите **▶️ Run** (или `Cmd+R`)

### Шаг 3: На iPhone
Если появится предупреждение:
- **Settings > General > VPN & Device Management**
- Найдите вашего разработчика
- Нажмите **Trust**

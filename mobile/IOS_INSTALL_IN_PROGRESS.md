## Что делать дальше

### 1. Дождитесь завершения сборки
Сборка может занять 3-5 минут. В терминале вы увидите прогресс.

### 2. На iPhone после установки

Если появится предупреждение **"Untrusted Developer"**:

1. Откройте **Settings** (Настройки)
2. Перейдите в **General** (Основные)
3. Найдите **VPN & Device Management** (VPN и управление устройством)
4. Найдите ваше имя/команду разработчика
5. Нажмите **"Trust [Your Name]"** (Доверять)
6. Подтвердите

### 3. Первый запуск

1. Откройте приложение **"Tutas Ai Mobile"** на iPhone
2. Войдите с учетными данными:
   - **Email:** `test@tutas.ai`
   - **Password:** `test123456`

### 4. Проверка подключения к API

Убедитесь, что:
- ✅ iPhone и Mac в одной Wi-Fi сети
- ✅ Backend запущен на Mac
- ✅ Backend доступен по адресу `http://192.168.49.65:8000`

Проверьте доступность backend:
- Откройте Safari на iPhone
- Перейдите на `http://192.168.49.65:8000/health`
- Должен вернуться JSON: `{"status": "healthy"}`

## Если что-то пошло не так

### Ошибка сборки
```bash
cd mobile
flutter clean
flutter pub get
cd ios && pod install && cd ..
flutter run -d 00008110-0008584C142A401E --release
```

### Ошибка подписи кода
1. Откройте Xcode: `open mobile/ios/Runner.xcworkspace`
2. Выберите проект **Runner** в навигаторе
3. Перейдите в **Signing & Capabilities**
4. Выберите вашу команду разработчика (Team)
5. Xcode автоматически создаст provisioning profile

### Устройство не найдено
```bash
# Проверьте подключенные устройства
flutter devices

# Если iPhone не виден:
# 1. Отключите и подключите USB кабель
# 2. На iPhone: нажмите "Доверять этому компьютеру"
# 3. Разблокируйте iPhone
```
